# 바이브 코딩 길잡이

경영지도사를 위한 8단계 바이브 코딩 자기주도 실습 웹페이지입니다. 서버 없이 HTML, CSS, JavaScript만으로 동작하는 정적 사이트입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 뼈대 (헤더, 목차, 본문 자리, 하단 문구) |
| `style.css` | 색, 글꼴, 배치 (밝은 화면과 어두운 화면 모두 지원) |
| `script.js` | 학습 내용 데이터(단계, 프롬프트, FAQ, 용어집)와 화면 전환, 복사, 진도 저장 기능 |

## 내 컴퓨터에서 열어 보기

폴더 안의 `index.html`을 더블클릭하면 브라우저에서 열립니다. 글꼴은 인터넷에서 불러오므로 인터넷에 연결되어 있어야 모양이 그대로 보입니다.

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만듭니다. (예: `vibe-guide`, 공개 저장소)
2. 이 폴더의 파일 3개(`index.html`, `style.css`, `script.js`)와 `README.md`를 저장소에 올립니다. Claude Code에게 "이 폴더를 GitHub 저장소에 올려 줘"라고 요청해도 됩니다.
3. 저장소의 Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save를 누릅니다.
4. 몇 분 뒤 `https://사용자이름.github.io/저장소이름/` 주소로 접속합니다.

기존 홈페이지에 연결하려면 홈페이지의 메뉴나 링크에 위 주소를 넣으면 됩니다.

## 내용 수정하기

학습 내용은 모두 `script.js` 위쪽의 데이터에 들어 있습니다.

| 고치고 싶은 것 | 찾을 곳 (script.js) |
| --- | --- |
| 프롬프트 추가·수정 | `var P=[` 로 시작하는 목록 |
| 단계의 설명, 체크포인트 | `var STEPS=[` 로 시작하는 목록 |
| 보고서 작성기 실습(실습 7) | `var REPORT=` |
| 자주 묻는 질문 | `var FAQ=[` |
| 용어집 | `var GLOSS=[` |

프롬프트에서 `{{이름}}` 모양은 학습자가 바꿔 넣는 빈칸입니다.

하단의 문의 이메일은 `index.html`의 `<span id="mail">`과 `script.js`의 `copy-mail` 부분 두 곳에 있습니다. 바꿀 때는 두 곳을 함께 고치세요.

Claude Code로 수정할 때는 이렇게 요청하면 됩니다.

```
script.js의 STEPS 데이터에서 Step 3 설명에 [추가할 내용]을 넣어 줘. 다른 부분은 그대로 두고, 수정 전에 계획을 먼저 보여 줘.
```

## 공개 전 점검

- 페이지와 코드에 휴대폰 번호, 비밀번호, API 키, 고객 정보가 없는지 확인합니다.
- Claude Code 설치 방법과 요금제 조건은 바뀔 수 있으므로 Step 4와 FAQ의 안내를 공식 문서와 비교합니다.
- 진도 표시는 학습자 브라우저에만 저장되며, 서버로 전송되지 않습니다.
